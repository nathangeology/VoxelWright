# Store screenshots

Drop final Creator Store images in this folder. Use PNG files made in the release build. Use original art or art with a clear license, and include any credit the license asks for.

Use these names so the store order stays clear:

1. `01-files-to-editable-parts.png`
2. `02-size-and-part-estimate.png`
3. `03-fewer-parts.png`
4. `04-texture-mapping.png`
5. `05-import-voxelize-optimize.png`

Capture at least 1600×900. Keep text large enough to read in a small thumbnail. Do not show personal information, copied Minecraft artwork, unmoderated images, or unfinished Dev-build controls.
