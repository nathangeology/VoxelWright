# Import a MagicaVoxel file

## What you need

- A MagicaVoxel file ending in `.vox`
- Permission to use the model
- VoxelWright open in Roblox Studio

## Steps

1. Save your model as a `.vox` file in MagicaVoxel.
2. In VoxelWright, click **Import File**.
3. Click **Choose Source File** and pick the `.vox` file.
4. Check the file name and model size.
5. Look for the preview box in the 3D view.
6. Set **Voxel size**. A value of `1` makes each voxel one stud wide.
7. Pick the placement you want.
8. Open **Advanced** if you need to turn the model by 90 degrees.
9. Click **Create Editable Parts**.

## Check your work

- The model should be near the preview box.
- Its colors and clear blocks should match the `.vox` file.
- The new model should contain normal Roblox Parts.

If the model points the wrong way, undo the build, change **Rotation**, and build it again.

MagicaVoxel and the `.vox` format are made by Ephtracy. See the [official MagicaVoxel site](https://ephtracy.github.io/).
