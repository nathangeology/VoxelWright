# Logo design brief

This brief turns outside design advice into rules for the VoxelWright logo.

## What the research says

- Apple says an icon should express one idea and stay clear at every size. It also suggests about 10% clear space around an icon and less detail in small versions. See [Apple's icon guide](https://developer.apple.com/design/human-interface-guidelines/icons).
- Adobe says a logo should identify a brand, not explain the whole product. It should work small, in one color, on light and dark backgrounds, and across many uses. Adobe also recommends owning one special shape instead of adding many ideas. See [Adobe's logo guide](https://www.adobe.com/express/learn/blog/how-to-design-a-logo).
- W3C uses a 3:1 contrast target for meaningful icons and other non-text graphics. Logos do not have to follow this rule, but it is a useful target for a toolbar button. See [W3C's icon contrast guide](https://www.w3.org/WAI/WCAG22/Techniques/general/G207).
- Roblox asks for a 512×512 image when a plugin is first published. The mark will also appear much smaller in Studio, so the 512-pixel image is not the only test. See [Roblox's plugin publishing guide](https://create.roblox.com/docs/studio/plugins#upload-plugins).

## Rules for VoxelWright

1. Use one main idea.
2. Make a shape someone could draw from memory.
3. Keep most of the mark inside the middle 80% of the canvas.
4. Test it at 16, 32, 64, 150, and 512 pixels.
5. Make sure it works in one color before adding the orange accent.
6. Test it on light and dark Studio colors.
7. Use thick shapes. Do not depend on thin lines or tiny squares.
8. Avoid a plain cube, a plain pencil, and a cube-plus-pencil stock symbol.
9. Join “voxel” and “maker” into one unusual shape.
10. Let store pictures explain the features. The logo only needs to identify VoxelWright.

## Brand system

VoxelWright needs two related pieces:

- **Primary interlock mark:** the fuller mark for the Creator Store, docs, and larger art.
- **Toolbar stamp:** the simpler D4 mark for small Studio buttons.
- **Store lockup:** the primary mark next to the VoxelWright name.

The store pictures can use more detail than the toolbar mark, but they should share the same colors and shapes.

## Round-two result

- **D3** has the most depth, but it is too busy for a small toolbar icon.
- **B2** explains editing well, but a pencil is still a common tool symbol.
- **B3** is the most original direction because it fuses a W, a maker's nib, and a voxel into one mark.
- **D4** is the clearest small mark, but it may need one more unusual cut or proportion to become memorable.

The primary interlock mark and D4 toolbar stamp are the chosen direction. No more concept generation is needed.

## Production cleanup

The chosen PNG files are concept art, not final masters. Before publishing:

1. Rebuild both marks as clean vector shapes.
2. Remove soft gradients and edge artifacts.
3. Set exact navy, teal, and orange color values.
4. Make the interlock and stamp use the same corner cuts and proportions.
5. Test both marks at 16, 32, 64, 150, and 512 pixels.
6. Make one-color, light-background, and dark-background versions.
7. Check that the primary mark and toolbar stamp still look like the same brand.
8. Run a final name and logo similarity check before the store submission.
