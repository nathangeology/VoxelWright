# Glossary

## Block state

Extra facts about a Minecraft block, such as the way a stair faces or whether a door is open.

## Common Shapes

An optional Minecraft Geometry choice that uses simple editable Roblox boxes for supported non-cube blocks, such as stairs, fences, chains, hanging signs, and plants.

## Bounds

The width, height, and depth of the full model.

## Greedy Cuboids

The plugin choice that joins as many matching blocks as possible. It usually makes the fewest Roblox Parts.

## Part

A basic 3D building object in Roblox Studio.

## Schematic

A file that stores a group of Minecraft blocks. VoxelWright reads Sponge `.schem` files from Java Edition tools such as WorldEdit.

## Solid fill

Voxel blocks on the outside and inside of a Studio model.

## Surface shell

Voxel blocks on the outside of a Studio model only.

## Texture ID

The number in a Roblox image asset link. VoxelWright uses it to place an image on a Part face.

## Textured Exposed Faces

An Appearance choice that places mapped Roblox images only on a Minecraft block face that is not fully covered by another block.

## Voxel

A small 3D block used to build a larger shape. It is like one square pixel with depth.

## World Range

The inclusive minimum and maximum X, Y, and Z block coordinates VoxelWright reads from an `.mcworld` archive.
