# Privacy

VoxelWright does not track how you use it or send plugin data over the internet.

The plugin reads a file only after you pick it with Studio's file window. This includes `.vox`, `.schem`, `.mcstructure`, and `.mcworld` files. It stores texture mappings and a few UI choices in local plugin settings.

Version 1 does not upload texture-pack files. Upload images through Roblox's Asset Manager or Creator Dashboard, then paste their IDs into VoxelWright. Roblox controls image review and access.

The local VoxelWright Dev preview can upload matching PNG files to Roblox after a second rights confirmation. It does not send the pack archive, structure, or model. It does not ask for an API key. Roblox currently blocks this feature in Creator Store plugins, so it is not in the version 1 store build.

VoxelWright creates Parts in the open Studio place. Studio Undo can remove each completed build or texture edit.

When you file a public issue, GitHub stores the text and files you submit. Do not post private places, paid models, secret keys, or files you do not have permission to share.
