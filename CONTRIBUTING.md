# Help improve VoxelWright

This repository holds public help pages and issue forms. The plugin source code is private.

You can help by:

- Reporting a bug
- Asking for a feature
- Pointing out a confusing help page
- Sending a pull request that fixes public documentation

Follow [WRITING.md](WRITING.md) when you change the docs.

Do not upload private places, paid models, copied game files, or texture art you do not have permission to share.
