# Get help

Start with the [quick start](docs/quick-start.md) or [Troubleshooting](docs/troubleshooting.md).

If you still need help:

- [Report a bug](https://github.com/nathangeology/VoxelWright/issues/new?template=bug-report.yml)
- [Ask for a feature](https://github.com/nathangeology/VoxelWright/issues/new?template=feature-request.yml)
- [Report a problem in the docs](https://github.com/nathangeology/VoxelWright/issues/new?template=docs.yml)

Do not post private places, secret keys, paid models, or files you do not have permission to share.
