# VoxelWright

VoxelWright turns voxel files and Studio models into Roblox Parts.

It can:

- Open MagicaVoxel `.vox` files.
- Open Java Edition `.schem` files.
- Open Bedrock Edition `.mcstructure` files.
- Turn a model in Studio into small 3D blocks called voxels.
- Join nearby blocks to make fewer Parts.
- Add your own Roblox texture images to Minecraft-style blocks.

VoxelWright is in private beta. The plugin code is kept in a private repository. This public repository holds help pages and the issue tracker.

## Safety and privacy

VoxelWright does not track how you use it or send plugin data over the internet. File reading and model building happen on your computer. You can remove a completed build with Studio Undo.

You must have permission to use and publish every model, structure, and texture you import.

## Minecraft notice

VoxelWright works with some files made for Minecraft. It does not include Minecraft, Minecraft textures, or other Mojang or Microsoft game files.
